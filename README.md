# Aylin Hosseinpour Barzegar — Academic Portfolio

An English, research-first academic portfolio with a circular portrait and refined editorial styling. Built with HTML, CSS and JavaScript; no paid services or build step required.

## Contents
- `index.html`: Main website, academic information, all 4 papers, 5 projects, education, grades, skills and contact links.
- `assets/css/styles.css`: Styling including the forest-green hero, circular photo and responsive layout.
- `assets/js/app.js`: Paper/project detail dialogs, course tabs and responsive navigation.
- `assets/img/profile.jpg`: **Original portrait supplied by the site owner** (embedded directly, not AI-modified).
- `assets/img/favicon.svg`: Site icon.
- `.nojekyll`: Allows GitHub Pages to serve assets as-is.

## Edit and preview
Open `index.html` in your browser, or open the folder with VS Code. The portrait is already connected. To change the photo, replace `assets/img/profile.jpg` with a new picture using the same filename. To change where the crop falls inside the circular frame, adjust `object-position` in the `.hero-portrait` CSS rule.

## Free GitHub Pages hosting
1. Create a public repository named `Aylin-Barzegar.github.io` under your own GitHub account (or use a different repository name and accept a `/repo/` path).
2. Upload **the contents of this folder**, not the parent folder, to the repository's root.
3. In the repo, open **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, then `main` and `/ (root)`.
4. When GitHub Pages completes deployment, use your published URL in your CV or project documentation. No custom domain is necessary and hosting costs nothing.

`noindex, nofollow, noarchive` is declared in the HTML for search engines. This requests exclusion from indexing but **does not make the website private** and cannot guarantee it will never appear in search results. The portrait and the rest of the repository will be publicly accessible to visitors and on GitHub.
